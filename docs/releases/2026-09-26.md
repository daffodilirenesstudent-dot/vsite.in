## Rollback

- **Fastest:** DigitalOcean console → Deployments → the previous deployment (`d119b2f`) →
  Redeploy.
- **Git (no force push):** a forward commit whose tree is the baseline —
  ```
  git checkout -b rollback/2026-09-26 master
  git read-tree -u --reset release/baseline-20260923
  git commit -m "revert: roll back to release/baseline-20260923"
  git push vsite rollback/2026-09-26:master
  ```
- **If 059 was already applied**, roll it back too: re-run the function body from
  `011_atomic_store_limits.sql`. The old code sends no consent, so with 059 in place a
  second store could not be created. 058 is expand-only and needs no rollback.
- Photos deleted by the new cleanup route are not recoverable by a rollback; it only ever
  deletes files no dish or banner references.
