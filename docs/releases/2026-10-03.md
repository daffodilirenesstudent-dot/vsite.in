## Rollback

- **Fastest:** DigitalOcean console → Deployments → the previous deployment (`acc18cf`) →
  Redeploy.
- **Git (no force push):** a forward commit whose tree is the previous release —
  ```
  git checkout -b rollback/2026-10-03 master
  git read-tree -u --reset release/2026-09-26
  git commit -m "revert: roll back to release/2026-09-26"
  git push vsite rollback/2026-10-03:master
  ```
- Migrations 062/063/064 are expand-only (new tables, cron jobs) and need no rollback; to
  stop the scheduler: `select cron.unschedule('whatsapp-dispatch'); select cron.unschedule('whatsapp-daily');`.
- Phone numbers filled into `profiles.phone_number` stay (they are the owners' verified
  numbers); the old code ignores them.
